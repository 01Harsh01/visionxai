# VisionX AI

VisionX AI is an end-to-end full-stack computer vision application powered by **FastAPI**, **PyTorch**, and a modern **React + Vite + TypeScript + Tailwind CSS** frontend.

---

## 🌟 Key Features

- **Object Detection:** Real-time object recognition and bounding boxes powered by **YOLOv8** (`ultralytics`).
- **Image Captioning:** Natural language scene descriptions generated by **Salesforce BLIP** (`blip-image-captioning-base`).
- **Visual Question Answering (VQA):** Interactive visual chat answering queries about visual content using **BLIP-VQA** (`blip-vqa-base`).
- **Text Extraction (OCR):** Optical character recognition across scenes and documents powered by **EasyOCR** and **OpenCV**.
- **Semantic Search:** Zero-shot image search with text queries in a joint latent space powered by **OpenAI CLIP** (`clip-vit-base-patch32`).
- **Dashboard & Analytics:** Real-time model inference and latency breakdown charts powered by **Recharts**.
- **Authentication:** Secure JWT authentication with Bcrypt password hashing and SQLite/PostgreSQL support.

---

## 🛠️ Tech Stack

- **Backend:** FastAPI, Uvicorn, PyTorch, Transformers, Ultralytics, EasyOCR, SQLAlchemy, Pydantic v2.
- **Frontend:** React 18, TypeScript, Vite, Tailwind CSS, Recharts, Lucide Icons, Axios.
- **Database:** SQLite (default for local development) / PostgreSQL 16 (production).
- **Deployment:** Docker, Docker Compose, Nginx, Railway.

## 🚀 Quick Start (Local Development)

### Windows 1-Click Launch:
Double-click [`start-visionx.bat`](start-visionx.bat) or execute:
```powershell
.\start-visionx.ps1
```

### Manual Setup:
1. **Configure Environment:**
   ```bash
   cp .env.example .env
   ```

2. **Backend:**
   ```bash
   cd backend
   pip install -r requirements.txt
   python -m uvicorn app.main:app --port 8000 --reload
   ```

3. **Frontend:**
   ```bash
   cd frontend
   npm install
   npm run dev
   ```

- **Frontend App:** [http://localhost:5173](http://localhost:5173)
- **API Documentation (Swagger):** [http://localhost:8000/docs](http://localhost:8000/docs)

---

## 🐳 Run with Docker Compose

```bash
docker compose up --build
```
- Frontend: `http://localhost:3000`
- Backend: `http://localhost:8000`

## ☁️ Cloud Deployment (Railway)

1. Sign up on **[Railway.app](https://railway.app)** with GitHub.
2. Click **+ New Project** &rarr; **Provision PostgreSQL**.
3. Add **Backend**:
   - Create service from GitHub repo &rarr; Set **Root Directory** to `/backend`.
   - Variables: `DATABASE_URL` (reference Postgres), `JWT_SECRET`, `CORS_ORIGINS=*`.
   - In **Settings** &rarr; **Networking**, click **Generate Domain**.
4. Add **Frontend**:
   - Create second service from GitHub repo &rarr; Set **Root Directory** to `/frontend`.
   - Variables: `BACKEND_URL` set to the backend generated domain.
   - In **Settings** &rarr; **Networking**, click **Generate Domain**.
